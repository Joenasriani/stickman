# In a Stickman's World

**Status:** original browser platform game  
**Play:** https://joenasr.itch.io/in-a-stickmans-world  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

In a Stickman's World is a minimalist browser platform game built around movement, jumping, enemies, hazards, collectibles and level progression.

## Game identity

Historical names include **Stick O Persia** and **Stickman World**. They belong to this same game lineage.

This game is distinct from:

- Stickman's Homework (`Joenasriani/stickmans-homework`)
- Threadbound (`Joenasriani/threadbound-game`)

Those projects share a stick figure visual language but are separate games.

Existing branches and historical files are retained as development history.
